*****************************
Full Morphology Method
*****************************

The **Full Morphology Method (FMM)** simulates pressure-driven fluid displacement using
morphological operations.

The method assumes:
- zero capillary number,
- strong wettability of the displaced fluid,
- immiscible fluids,
- a quasi-static process,

such that equilibrium is achieved between consecutive iterations.

The saturation map is generated by **sphere intrusion**.
It is based on the simplified **Young–Laplace equation**, which assumes cylindrical throats.
This equation relates the capillary pressure to the invaded radius:

.. math::
   :nowrap:

    $$
    P_c = \frac{2 \gamma \cos(\theta)}{R},
    $$

where $\gamma$ is the interfacial tension, $\theta$ is the contact angle,
and $R$ is the invaded radius. 

For a given radius, the algorithm consists of three main steps: **erosion**, **connectivity check** and **dilation**.
During the **erosion** step, voxels within the pore space whose Euclidean Distance Transform (EDT) is greater than or equal to the current radius are identified.
These voxels represent candidate sphere centers that the injected fluid can occupy.

From this set, the **connectivity check** retains only the voxels that are connected to the inlet. This step prevents 
invasion from occurring within isolated regions in the interior of the domain, ensuring that the  displacement process
remains physically consistent.

Finally, **dilation** is applied to this filtered set of sphere centers. Voxels located within a distance equal to the radius from these centers are relabeled as
invaded, completing the algorithm for the given radius.

This process can be repeated for a set of decreasing radii, which gives the relation between saturation and pressure. The Young-Laplace equation translates this
relation into $P_c$-saturation data, resulting in a capillary curve or MICP (mercury injection capillary curve) depending on the protocol adopted, as described below.

**Protocols**

The algorithm employed in this routine is adapted from **ZABOT** and has two protocols: **drainage** and **micp**.

The **drainage** protocol simulates an incompressible displacement with intrusion from a single face, chosen by the user.
Because the displaced fluid is incompressible, regions of trapped fluid may remain within the pore space.
 
Protocol **micp** invades the sample from all faces, and the displaced fluid is set as compressible. As a result, all pores connected to the
exterior are filled with a sufficiently small radius. This protocol mimics a porosimetry experiment, in which mercury is injected in a porous media under 
vacuum conditions.


.. *****************************
.. Digital mercury injection capillary curves
.. *****************************

.. LBPM includes a routine to perform digital mercury injection capillary curves (MICP) experiments through the Full Morphology method. The ``ylm-comp`` algorithm performs non-wetting fluid intrusion by introducing spheres with progressively decreasing radius in the porous media.

.. The invaded fluid connection to the inlet faces is checked to simulate the invasion as it happens on the physical experiment, so bigger pores which are disconnected to the inlet are not invaded until a smaller throat connects them to the inlet.


.. Input
.. -----

.. The input file format is given by 

.. .. code:: c

.. 	  Domain {
.. 		Filename = "example.raw"
.. 		N = 100, 100, 100            // domain size
.. 		VoxelLabels = 0, 1, 2, 3     // solid, vacuum, injected, pore (PORE NÃO FAZ SENTIDO, TIRAR DO CÓDIGO)
.. 		}

.. 	  YLM {
.. 		Diameters = 2, 50, 1         // smallest, biggest, step
.. 		ImageRoot = "img"            // name files
.. 		ImageDir = "folder"          // folder in which data is saved
.. 		WhichImage = "all"           // which image to save: all, last, none
.. 		Direction = 0, 0, 1          // axis of intrusion (accepts negative values) (não precisa para MICP, tirar do código)
.. 		Surround = true              // Surrounds the sample with injected fluid if needed (acho que dá pra deixar true default)
.. 		}

.. Once this has been set, ``ylm-comp`` routine is launched via

.. .. code:: bash

.. 	  mpirun -np 1 $LBPM_DIR/tests/ylm-comp input.db


.. Note that this routine does not run in parallel computation.

.. Comparisons
.. -----------

.. This routine is similar to the ``lbpm_morphdrain_pp`` (read more about it `here <./morphOpen.html>`__), except the latter relies solely on the Euclidian distance transform, injecting from the biggest pores even though they might be disconnected to the inlet.

.. An IBS sandstone sample was used to compare both routines to experimental data . Both curves were reescaled to match the saturation of the minimal diameter to the experimental one. The figure bellow presents such curves.


.. .. figure:: ../../_static/images/ylm-lbpm.png
..     :width: 600
..     :alt: morphdrain

..     Digital MICP (blue) and lbpm_morphdrain_pp (orange) compared to experimental data (black dashed).

.. The saturation on the ``ylm-comp`` curves are higher on bigger diameters because this method interprets reservoirs on all faces, allowing semi-sphere intrusions. ``lbpm_morphdrain_pp`` simulations were performed with periodic boundaries.
