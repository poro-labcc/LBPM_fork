Representative Elementary Volume (REV) Analysis (lbpm_rev_analysis)¶

The degree of heterogeneity observed in digital rocks is an important factor in characterizing porous media. Advances in the resolution and sample size achievable with X-ray microtomography have made it increasingly feasible to digitally investigate larger volumes that capture the intrinsic heterogeneities of porous structures. These developments enable the identification of representative elementary volumes (REVs), beyond which the influence of local heterogeneities becomes negligible and specific effective properties of the porous medium can be reliably characterized.

The lbpm_rev_analysis routine provides an automated REV analysis for a range of geometrical and hydrodynamic properties, as summarized in Table 1. By combining deterministic and statistical approaches, the routine enables a comprehensive characterization of these properties, providing valuable insights for assessing the representativeness of microtomography images and estimating effective sample volumes for subsequent numerical analyses.

Table 1 Properties available for REV analysis.¶

Property 1

Property 2

Geometrical

Porosity (\(\phi\))

Superficial Area (\(A_{s}\))

Hydrodynamic

Hydraulic Tortuosity (\(\tau_{h}\))

Methodology¶

The implemented REV routine combines deterministic and statistical approaches into a hybrid methodology, as illustrated in the workflow diagram presented in Fig. 5. The deterministic stage provides an initial estimate of the REV size at a relatively low computational cost. This estimate is subsequently used to initialize the statistical stage, which evaluates the spatial variability of the property over randomly distributed subvolumes. The deterministic analysis uses a default convergence threshold of \(\gamma = 0.1\). The statistical stage reports coefficients of variation and retains the first porosity and permeability sizes below this tolerance. For a detailed explanation of the steps illustrated in Fig. 5, expand the toggle sections below for the deterministic and statistical analyses.

Deterministic Analysis¶

Click here to open: Deterministic Analysis

The deterministic approach evaluates a property of interest within a subvolume centered in the computational domain. The analysis is repeated for progressively larger subvolumes until the measured property becomes approximately independent of the subvolume edge length. The smallest subvolume satisfying the prescribed convergence criteria is identified as the deterministic REV.

The main advantage of this approach is its relatively low computational cost, as only one subvolume is evaluated for each edge length. However, the results may be sensitive to local fluctuations, including maxima, minima, and inflection points, potentially leading to false convergence.

The deterministic procedure, illustrated in the upper part of the workflow diagram, consists of the following steps:

  1. Initialize the subvolume size: The initial edge length is defined as twice the average pore diameter,

    (110)¶\[\ell_0 = 2\overline{d}_p.\]

  2. Evaluate the domain-size constraint: Before each evaluation, the subvolume dimensions are checked against the available computational domain. If the prescribed maximum size is exceeded before convergence, no deterministic REV is identified.

  3. Measure the property: The property of interest, \(\eta_i\), is evaluated within the centered subvolume.

  4. Compute the convergence criteria: Two complementary metrics are calculated to quantify the variation of the measured property with increasing subvolume size.

    The first metric is the relative error (RE), defined as

    (111)¶\[RE_i = \left| \frac{q_i-q_{i-1}} {q_i+q_{i-1}} \frac{V_{i-1}}{V_i} \right| < \gamma,\]

    where \(RE_i\) is the relative error at iteration \(i\), \(q_i\) represents the measured property in the \(i\)-th subvolume, and \(V_i\) denotes the volume of that sampled subvolume. This metric quantifies the local variation of the property as the evaluated subvolume increases in size.

    The second metric is the convergence criterion (CC), introduced by Marafini et al. [4]:

    (112)¶\[CC_i = \frac{ \sigma(\eta_{i-m+1},\ldots,\eta_i) }{ \overline{\eta}(\eta_{i-m+1},\ldots,\eta_i) } < \gamma,\]

    where \(\sigma\) denotes the standard deviation, \(\overline{\eta}\) represents the arithmetic mean, and \(m\) is the number of consecutive measurements considered. By evaluating the dispersion of the most recent measurements, this metric reduces the likelihood of false convergence associated with local fluctuations. The default value is \(m=10\).

  5. Assess convergence and update the subvolume size: The first subvolume size for which both convergence criteria satisfy the prescribed tolerance is recorded as the deterministic REV for each property. Sizes continue to increase up to the maximum admissible domain size. The proportional growth is controlled by SizeStep; for example, SizeStep = 0.06 gives the nominal update

    (113)¶\[\ell_{i+1}=1.06\ell_i,\]

    The implementation also applies a minimum increment based on the average pore diameter and rounds the edge length upward to whole voxels, so the actual increase can be larger. The default SizeStep is 0.1 (10%).


Statistical Analysis¶

Click here to open: Statistical Analysis

The statistical approach evaluates the spatial variability of a property by sampling multiple subvolumes distributed throughout the computational domain. For a given edge length, the property is measured in a set of randomly selected subvolumes, and the dispersion of the resulting measurements is assessed.

The current implementation repeats this sampling for increasing subvolume sizes and reports the dispersion at each size. These results can be compared with the prescribed tolerance to identify sufficiently consistent measurements.

Compared with the deterministic approach, statistical analysis is computationally more expensive because multiple subvolumes must be evaluated at each edge length. Nevertheless, it provides a more robust assessment of spatial heterogeneity and reduces the risk of identifying false convergence caused by localized features.

An important limitation arises as the subvolume size approaches the dimensions of the computational domain. In this situation, increasing overlap between sampled subvolumes can artificially reduce the measured dispersion, potentially leading to an overestimation of convergence.

The statistical procedure, represented in the lower part of the workflow diagram, follows these steps:

  1. Initialize the statistical analysis: The edge length corresponding to the deterministic REV is adopted as the initial subvolume size, avoiding the repeated evaluation of smaller volumes that have already been assessed.

  2. Select and evaluate random subvolumes: For the prescribed edge length, \(N\) subvolumes are randomly distributed within the computational domain, and the property of interest is evaluated independently in each subvolume.

  3. Evaluate statistical convergence: The dispersion of the measurements is quantified using the coefficient of variation (CV), following Zhang et al. [5]:

    (114)¶\[CV = \frac{\sigma(\eta)}{\overline{\eta}} < \gamma,\]

    where \(\sigma(\eta)\) is the standard deviation of the property measurements and \(\overline{\eta}\) is their arithmetic mean. Normalization by the mean provides a dimensionless measure of relative dispersion.

    The number of sampled subvolumes is fixed by StatSamples and defaults to 50 at each size. The current routine does not adapt this count based on the stability of the estimated CV.

  4. Assess the statistical REV: The routine retains the first size with 0 <= CV < gamma independently for porosity and permeability, together with its mean and dimensions. It continues reporting the subsequent sizes using SizeStep and the minimum increment described above until the admissible domain-size limit is reached. SubdomainSelect optionally uses these retained results to select representative windows.


Run REV Analysis¶

REV analysis can be performed either alongside a single-phase permeability simulation using lbpm_rev_permeability_simulator, or independently using lbpm_rev_analysis.

Currently, neither routine supports parallel execution across multiple MPI processes. Therefore, both routines must be executed using a single MPI process. To ensure compatibility, the Domain configuration must be set to nproc = 1, 1, 1 in the corresponding configuration block.

lbpm_rev_permeability_simulator¶

The lbpm_rev_permeability_simulator executable runs the single-phase flow simulation, computes the velocity field, and then performs deterministic and statistical REV analyses. A typical command for a single-process run is:

mpirun -np 1 lbpm_rev_permeability_simulator input.db

The standard lbpm_permeability_simulator executable does not invoke the REV routines. Use the REV-enabled executable above for the combined workflow. REV analysis is activated by the presence of a REV block in input.db, alongside the usual Domain and MRT blocks. For example:

REV {
   Geometrical = True
   Hydraulic = True
   gamma = 0.1
   SizeStep = 0.06
   CCInterval = 10
   StatSamples = 50
   Seed_Anchor = True
}

lbpm_rev_analysis¶

The routine lbpm_rev_analysis performs REV analysis from an input geometry. Geometrical analysis requires the geometry alone; hydraulic analysis also requires velocity fields saved by an earlier single-phase flow simulation.

mpirun -np 1 lbpm_rev_analysis input.db

For geometrical analysis alone, the geometry is sufficient. Hydraulic defaults to False in this routine, so porosity and specific surface area can be evaluated without loading velocity fields. This default can also be set explicitly:

REV {
   Geometrical = True
   Hydraulic = False
   Seed_Anchor = True
}

An MRT block is not required for this configuration. Set Hydraulic = True explicitly to enable hydraulic analysis when previously saved flow results are available. However, this analysis requires velocity fields obtained from a prior single-phase flow simulation. For example, the following configuration block enables both property groups:

REV {
   Geometrical = True
   Hydraulic = True
   Seed_Anchor = True
   SimulationParams = "/path/to/simulation/input.db"
   VelocityPath = "/path/to/simulation/results"
   VelocityTimestep = "vis3000"
}

When Hydraulic = True, all three settings, SimulationParams, VelocityPath, and VelocityTimestep, must be explicitly supplied and nonempty. If any are missing or blank, lbpm_rev_analysis prints a message listing them and exits with a nonzero status before loading the saved files or geometry. These settings are not required for geometrical analysis alone.

Note that, in addition to the velocity fields saved in the vis* folder, it is also necessary to provide the path to the input.db file used in the previous single-phase flow simulation. This file is required to retrieve the pressure drop and fluid viscosity used to calculate the absolute permeability.

Model parameters¶

For a detailed description of the REV analysis parameters, expand the section below using the toggle button.

Click here to open: REV Parameters

Geometrical and Hydraulic select the property groups evaluated in both analysis stages. Setting Geometrical = True enables porosity and specific surface area analysis, while Hydraulic = True enables permeability and hydraulic tortuosity analysis. Setting either parameter to False skips its corresponding group. Geometrical defaults to True in both routines. Hydraulic defaults to False in lbpm_rev_analysis and to True in lbpm_rev_permeability_simulator. An explicit setting overrides the default. Setting both parameters to False skips both REV analyses.

gamma is the dimensionless convergence tolerance, with a default value of 0.1. A deterministic REV is identified for a property when both its relative error (RE) and convergence criterion (CC) are valid and smaller than gamma. The statistical analysis independently retains the first porosity and permeability sizes with a valid coefficient of variation (CV) below gamma, together with their respective means and window dimensions. For example, gamma = 0.1 requires both metrics to be below 10%. A smaller value imposes a stricter convergence requirement and may lead to a larger REV estimate or prevent convergence within the available domain.

SizeStep controls the proportional increase in subvolume edge length in both analysis stages. The example value 0.06 specifies a 6% increase in edge length between successive subvolume sizes, corresponding to an approximate 19% increase in volume. The implementation also enforces a minimum increment equal to the larger of one voxel and the average pore diameter, and rounds the resulting edge length upward to an integer number of voxels. Consequently, the actual increase can exceed 6%, especially for small subvolumes. If omitted, SizeStep defaults to 0.06. It must be positive.

CCInterval is the number of recent subvolume-size measurements used to calculate CC in the deterministic analysis. With CCInterval = 10, CC measures the relative dispersion of up to the ten most recent measurements; the available measurements are used before the window is full. Increasing this value assesses convergence over a longer history of subvolume sizes. It must be a positive integer and defaults to 10.

StatSamples is the number of randomly positioned subvolumes evaluated at each size during the statistical analysis. With StatSamples = 50, each property is sampled in 50 subvolumes to calculate its mean, minimum, maximum, and coefficient of variation (CV). Increasing this value provides more spatial samples at a higher computational cost. It must be a positive integer and defaults to 50.

Seed_Anchor controls the random generator used to position subvolumes in the statistical analysis. It defaults to True in both routines, which initializes std::mt19937 with the fixed seed 0 and makes sampling reproducible for the same input and configuration. Set Seed_Anchor = False to initialize the generator with a seed from std::random_device, allowing the sampled locations to vary between runs. This parameter does not affect the deterministic analysis.

SubdomainSelect defaults to False. Set it to True to select representative subdomains after the statistical analysis, using its retained REV sizes and means. See Representative subdomain selection for the numerical workflow, input restrictions, and outputs.

SimulationParams identifies the input database used for the flow simulation. The referenced database must contain an MRT block, from which the routine reads the relaxation time tau and body-force vector F. A relative path is resolved against the directory containing the analysis input database. The referenced file supplies only these flow parameters; keep the geometry and REV settings in the analysis database. SimulationParams is required when hydraulic analysis is enabled in lbpm_rev_analysis.

VelocityPath is the directory containing the saved LBPM output. Relative paths are resolved from the current working directory. VelocityTimestep selects a timestep directory within this path and must be supplied as a quoted string. Both settings are required when hydraulic analysis is enabled in lbpm_rev_analysis. Use VelocityPath = "." to select the current working directory explicitly.

The selected timestep must contain LBM.summary and a domain mesh with the scalar volume fields Velocity_x, Velocity_y, and Velocity_z. The saved output must contain a single MPI domain whose dimensions match the analysis geometry. Use the same geometry and voxel length as the original simulation. For an MRT simulation, enable write_silo = True in its Visualization block to save the required velocity fields in LBPM output.


The property-selection, convergence, sampling, and subdomain-selection parameters are optional. The three saved-flow settings are required for standalone hydraulic analysis. An empty REV block activates geometrical analysis in lbpm_rev_analysis and both property groups in lbpm_rev_permeability_simulator, with gamma = 0.1, SizeStep = 0.1, CCInterval = 10, StatSamples = 50, and Seed_Anchor = True. Omitting the entire block disables REV analysis.

Representative subdomain selection¶

Enable SubdomainSelect in input.db to select representative windows in either REV executable. For porosity selection alone:

REV {
   Geometrical = True
   Hydraulic = False
   SubdomainSelect = True
   gamma = 0.1
   StatSamples = 50
   Seed_Anchor = True
}

For permeability selection, set Hydraulic = True and supply the saved-flow settings described above. Porosity and permeability use their independently retained statistical REV sizes and means, without repeating REV analysis. The selected window has the dimensions used to calculate the corresponding mean: L x L x L for a cubic image, or the statistical analysis’s proportionally scaled dimensions for a rectangular image.

The selection scans every valid position, moving one voxel along each axis and including the last window at each boundary. It minimizes \(|p_{\mathrm{local}}-\overline{p}_{\mathrm{REV}}| / |\overline{p}_{\mathrm{REV}}|\) separately for each property. A zero mean gives zero deviation for an exact zero and infinite deviation otherwise. Equal deviations select the first candidate, with x changing fastest, then y and z. An exact match does not stop the scan.

Porosity counts voxels with positive signed distance, following the existing analysis convention. Permeability is evaluated by a fresh numerical MRT flow simulation of each cropped geometry, followed by the existing Darcy conversion to millidarcies. The retained statistical hydraulic mean is calculated from the earlier full-domain simulation; changing to a cropped geometry with periodic boundaries can change its flow response.

Selection requires one MPI process and rejects nonzero Domain.InletLayers or Domain.OutletLayers because synthetic reservoir layers would differ from the original raw image. Hydraulic selection requires periodic flow (BC = 0) and a nonzero body force, and uses the same tau and force vector as the hydraulic analysis. Solver limits come from the SimulationParams MRT block, or the local MRT block if no reference is supplied: timestepMax defaults to 100000, analysis_interval to 1000, and tolerance to 1e-8. Failure of any candidate simulation to converge stops selection with an error. For a cubic window of edge length \(L\), there are \((N_x-L+1)(N_y-L+1)(N_z-L+1)\) candidates. Running a flow simulation for each can be substantially more expensive than statistical REV analysis.

Selection writes the following files in the current working directory:

  • subdomain_porosity.raw and subdomain_permeability.raw contain the independent selected crops, with x varying fastest and no halo voxels. Domain.Filename input with ReadType = "8bit" or "16bit" is copied byte for byte, preserving original labels and data type before relabeling. ID.00000 input retains its original one-byte labels with halos removed. GridFile and swc input are unsupported for selection.

  • subdomain_selection.csv uses comma separators and records each property’s status, REV size in voxels and micrometres, dimensions and physical lengths, statistical mean, selected value, relative deviation, number of candidates, raw filename, and source layout. Coordinates use zero-based indices and exclusive upper bounds. x0,y0,z0 and x1,y1,z1 refer to the halo-free analysis image. The source_* coordinates include Domain.offset or the input halos of ID.00000; source dimensions and bytes per voxel allow the crop to be reproduced directly from the original file.

A disabled property or one without a converged statistical REV receives a status row and produces no raw crop.

When calling the C++ API directly, invoke rev.sub_domain_select() after rev.StatRevAnalysis(), or rev.sub_domain_select(model) after rev.StatRevAnalysis(model). These selection calls return immediately when SubdomainSelect is disabled.

Assessing Output Data¶

As an examples for the output data analysis, we perform a REV analyses for Berea sample (also analyzed in 3D Digital Rocks) using both routines lbpm_rev_permeability_simulator and lbpm_rev_analysis. In the present case we will set Seed_Anchor = True to keep reproducibillity of the present results. For the present analysis we employ a geometrical and hydraulic REV analysis:

lbpm_rev_permeability_simulator¶

Running the REV analysis inside of the routine lbpm_rev_permeability_simulator

MRT {
tau = 0.9
F = 0.0, 0.0, 1.0e-4
timestepMax = 200000
tolerance = 0.00001
}
Domain {
   Filename = "Berea.raw"
   ReadType = "8bit"      // data type
   N = 400, 400, 400     // size of original image
   nproc = 1, 1, 1        // process grid
   n = 400, 400, 400      // sub-domain size
   offset = 0, 0, 0 // offset to read sub-domain
   InletLayers = 0, 0, 10 // specify 10 layers along the z-inlet
   OutletLayers = 0, 0, 10 // specify 10 layers along the z-outlet
   voxel_length = 5.345    // voxel length (in microns)
   ReadValues = 0, 1   // labels within the original image
   WriteValues = 1, 0  // associated labels to be used by LBPM
   BC = 0                 // boundary condition type (0 for periodic)
}
REV {
   Geomtrical = True
   Hydraulic = True
   gamma = 0.1
   SizeStep = 0.06
   CCInterval = 10
   StatSamples = 50
}
Visualization {
   write_silo = true     // write SILO databases with assigned variables
   save_velocity = true    // save velocity field within SILO database
}

Results are written to the current working directory. Enabled geometrical analysis produces det_rev_geometric.csv and stat_rev_geometric.csv; enabled hydraulic analysis produces det_rev_hydraulic.csv and stat_rev_hydraulic.csv. The routine also writes pore_size_distribution.csv when an analysis group is enabled. For a detailed description of the output data printed in det_rev_geometric.csv, stat_rev_geometric.csv, det_rev_hydraulic.csv and stat_rev_hydraulic.csv, expand the section below using the toggle button.

Click here to open: .csv Output Data

All four REV files are plain-text tables with a header row. Despite the .csv extension, fields are separated by spaces, so use a whitespace delimiter when importing them. Results are appended to existing files, and the header is written only when a file is empty. Separate runs therefore accumulate in the same table without a run or timestep identifier.

The suffixes _vx and _um indicate lengths in voxels and micrometres, respectively. With \(h\) equal to Domain.voxel_length in micrometres, x_size_um = x_size_vx * h. These columns report the reference size in the \(x\) direction; the other subvolume dimensions follow the domain aspect ratio, subject to integer rounding.

Attention

For interpreting the values actually written to the deterministic tables, let \(q_i\) denote the property measured at size iteration \(i\). The implemented relative-change calculation is

(115)¶\[RE_i = \left| \frac{q_i-q_{i-1}}{q_i+q_{i-1}} \frac{V_{i-1}}{V_i} \right|.\]

Here, \(V_i\) is the actual sampled volume, calculated from the inclusive voxel bounds after clipping to the domain. The implementation uses the ratio of sampled voxel counts because the common voxel volume cancels in \(V_{i-1}/V_i\).

CC is the population standard deviation divided by the arithmetic mean of the most recent CCInterval measurements, using the available history before that window is full and excluding invalid values. For tortuosity, \(q_i = \tau_{h,i}-1\) in both calculations. The coefficients are dimensionless fractions: 0.05 corresponds to 5%.

A property’s rev_* columns are set when both RE and CC first satisfy \(0 \le RE < \gamma\) and \(0 \le CC < \gamma\). The accepted size is retained in subsequent rows even if the coefficients later increase. The analysis continues through the full domain, so the last row’s x_size_* need not equal the identified REV size.

Before a property converges, rev_*_vx is -1 and rev_*_um is -h because the voxel sentinel is multiplied by the voxel length. If these values persist to the last row, no deterministic REV was found for that property. Unavailable RE or CC values are written as -1; both are unavailable on the first row. A zero normalization denominator also leaves the corresponding coefficient at -1.

Attention

For each statistical property, CV is the population standard deviation divided by the mean over valid samples; internal values equal to -1 are excluded. The population standard deviation uses the number of valid samples as its divisor. A CV of 0.05 means 5% relative dispersion. -1 means that CV is unavailable, either because no samples are valid or because the mean used for normalization is zero. Neither the number of valid samples nor the standard deviation is written separately.

The statistical size sequence begins at the smallest deterministic REV found among the enabled properties. If none was found, it begins at twice the average pore diameter. Sizes then increase while remaining smaller than the full domain’s \(x\) extent. Consequently, the statistical and deterministic files can contain different size sequences and row counts; compare them using x_size_vx or x_size_um. If the initial statistical size already reaches the domain limit, the file has no data rows for that run.

Note

The current tortuosity calculation always uses the \(z\) velocity component, even if the body force points in another direction. A zero summed \(z\) velocity gives an invalid internal tortuosity value, which is printed as 0 in the deterministic file and excluded from statistical calculations. If all tortuosity samples at a size are invalid, stat_tort is -1 and the reported mean, maximum, and minimum are initialization artifacts (1, 0, and approximately 1e100); these are not physical tortuosity statistics.


The results obtained by the Berea sample are illustrated in the Fig. 7, for the data porosity, superficial area, absolute permeability, and hydraulic tortuosity. The python code use generate the below plot is shared in the toogle button below the plot.

rev_threshold = 0.10

stat_hyd = np.genfromtxt("stat_rev_hydraulic.csv", names=True)
# -------------------- Deterministic data --------------------
tamanho_um = det_geo["x_size_um"]
tamanho_vx = det_geo["x_size_vx"]
porovec = det_geo["porosity"]
kabsvec = det_hyd["permeability"]
tortvec = det_hyd["tortuosity"]

def first_rev_size(sizes, cv, threshold):
   valid = np.where( np.isfinite(cv) & (cv >= 0) & (cv < threshold) )[0]
   return sizes[valid[0]] if valid.size else None

def reported_rev_size(data, column):
   values = data[column]
   valid = values[np.isfinite(values) & (values > 0)]
   return valid[-1] if valid.size else None

   rev_tort = first_rev_size( tamanho_stat_um, cv_tort, rev_threshold )
   rev_surf = first_rev_size( tamanho_stat_um, cv_surf, rev_threshold )
